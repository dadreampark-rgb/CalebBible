# 2027 신년 목회계획 수립 워크샵 — 8시간 커리큘럼

**부제**: Claude Code를 활용해 하루 만에 컨설팅급 목회계획서를 완성한다
**대상**: 중소형 교회 담임목사(단독 목회)
**진행 방식**: 각 세션은 ① 미니 강의(개념) → ② 담임목사 입력(기도·작성) → ③ Claude Code 실행(생성·정리) → ④ 검토·확정 순서로 반복
**결과**: 워크샵 종료 시 완성된 목회계획서 패키지(문서1의 7종 산출물) 손에 들고 귀가

---

## 설계 사상

8시간 안에 컨설팅급 결과를 내려면 "배우는 시간"과 "만드는 시간"을 분리하면 안 됩니다. 이 커리큘럼은 **만들면서 배우는** 구조입니다. 매 세션 끝에 반드시 손에 잡히는 산출물 하나가 남습니다. Claude Code는 강사가 아니라 **각 목사 옆에 앉은 컨설턴트**처럼 작동합니다 — 입력을 받아 즉석에서 차트·표·문서를 만들어 돌려줍니다.

### 결정적 전제: 참가자는 빈손으로 온다

현실을 직시합니다. **워크샵에 교회 자료(통계·예산서·등록부)를 챙겨 오는 목사는 거의 없습니다.** 이전 설계는 사전 과제로 데이터를 모아 오게 했지만, 그 전제가 무너지면 진단 세션 전체가 멈춥니다. 그래서 이 커리큘럼은 **자료가 0이어도 100% 작동**하도록 다시 설계했습니다.

유일하게 가져오는 것은 목사 자신의 **머리와 지난 1년의 기억**입니다. 세션 1은 데이터를 입력받는 시간이 아니라, Claude가 날카로운 질문으로 그 기억을 끄집어내는 **회상 인터뷰**입니다. 이것이 외부 컨설팅이 흉내 낼 수 없는 이 프로그램의 경쟁력입니다 — 컨설턴트는 자료를 요구하지만, 우리는 빈손의 목사에게서 강력한 계획을 끌어냅니다.

---

## 사전 준비 (워크샵 D-7 ~ D-1)

**참가자 사전 과제 — 자료 수집이 아니라 '회상 워밍업'** (파일 지참 불필요)
- 가져올 것은 **마음과 기억뿐**. 통계나 서류를 찾느라 부담 갖지 않도록 명확히 안내(이것이 참석률을 높임)
- 워크샵 전 조용한 시간에 지난 1년을 기도하며 돌아보기 — "올해 가장 기뻤던 순간 / 가장 아팠던 순간"을 떠올려 보기
- (선택, 강제 아님) 떠오르는 새가족·새 리더의 이름을 메모지에 적어 오면 회상이 빨라짐
- 올해 기도 중 반복해 떠오른 키워드·본문 메모

**운영팀 준비**
- 각 좌석에 Claude Code 환경 세팅(또는 데스크톱 앱) + 신년목회계획 스킬 패키지(문서3) 설치
- `guided-recall` 스킬이 회상 인터뷰 질문 세트로 준비되어 있는지 확인
- 워크북(인쇄), 회상을 돕는 '작년 12개월 빈 타임라인' 인쇄물, 기도 시간용 별도 공간
- (자료를 우연히 가져온 목사가 있으면 보조 입력으로 활용하되, 없음을 전제로 진행)

## 세션별 상세 진행안

### 세션 0 — 오리엔테이션 + 경건회 (09:00–09:30, 30분)

- 워크샵 목표와 하루 흐름 안내(5분)
- 짧은 말씀·기도로 마음을 엶 — "계획하는 마음이 주께 있다"(잠 16:9) (15분)
- Claude Code 기본 사용법 시연: "이렇게 입력하면 이렇게 돌아온다" 라이브 데모 1회(10분)
- *도구는 종이고 분별의 주인은 하나님과 목자임*을 분명히 함

**Claude 활용**: 진행자가 샘플 데이터로 진단 차트가 1분 만에 생성되는 장면을 시연 → 신뢰와 기대 형성.

---

### 세션 1 — 진단: 기억에서 길어 올리는 우리 교회 (09:30–10:40, 70분)

> 이 세션의 전제: **참가자는 자료가 없다.** 그래서 데이터를 '입력'하는 시간이 아니라, Claude가 질문으로 목사의 기억을 '인출'하는 회상 인터뷰로 진행합니다.

**① 미니 강의 (10분)**: 자료가 없어도 강력한 진단이 가능한 이유 — 목자는 숫자는 잊어도 양은 기억한다. 깔때기(전도→정착→양육→리더) 어디가 새는지는 기억만으로도 보인다.

**② 회상 워밍업 (15분)** — 인쇄된 '작년 12개월 빈 타임라인'에 1월부터 떠오르는 사건·사람·절기를 손으로 적으며 기억을 데움.

**③ Claude 회상 인터뷰 + 진단 (30분)** — `grill-me-docs` → `guided-recall` → `church-diagnostics` 스킬
- **`grill-me-docs`가 인터뷰를 주도**: 한 답에 멈추지 않고 적응형 꼬리질문을 연쇄로 던져 기억을 집요하게 인출 — "그 새가족 어떻게 정착했나요?", "누가 연결했죠?", "작년 3월엔 뭐가 있었죠?"
- 같은 사실을 다른 각도로 되물어 최신·낙관·선명성 편향 보정(grill-me-docs의 반복 심문 기능)
- `guided-recall`이 응답을 받아 출석·등록 등을 **범위 추정치 + 신뢰수준(상/중/하)** 으로 정규화
- `church-diagnostics`가 추이 방향(↑↓→), 깔때기 전환 감각, 건강 8영역 레이더 차트, Top 3 강점/시급 과제 생성

**④ 검토·확정 (15분)**: 목사가 Claude의 해석을 현장 감각으로 교정. 신뢰 '하'로 표시된 항목은 "워크샵 후 교회에서 확인할 것" 목록으로 분리.

**산출물**: 교회 현황 진단 대시보드(추정치·신뢰수준 표기) + 작년 12개월 회상 타임라인

> 진행 팁: 자료 없음을 부끄러워하지 않도록 분위기를 만드는 것이 이 세션의 절반입니다. "기억이 곧 데이터"임을 반복해 안심시킵니다.

---

### 세션 2 — 분별: 하나님이 올해 무엇을 원하시는가 (10:50–11:40, 50분)

**① 미니 강의 (8분)**: 좋은 표어의 3요건 — 성경적·상황구체적·행동번역가능.

**② 기도·입력 (12분)**: 진단 결과를 앞에 두고 조용히 기도하며 키워드·본문을 적음.

**③ Claude 실행 (18분)** — `vision-discernment` 스킬
- 표어 후보 3안(영성형/전도형/공동체형) + 각 핵심 본문·주해 요약
- 표어→3축 연결 논리 점검
- 연계 설교 시리즈 골격 제안

**④ 분별·확정 (12분)**: 목사가 한 안을 택하거나 합성. 방향 선언문 1단락 확정.

**산출물**: 연간 표어 + 핵심 본문 + 목회 방향 선언문

> 진행 팁: 이 세션은 도구가 답을 주는 시간이 아니라 **분별을 돕는** 시간임을 거듭 강조. Claude는 선택지를 펼칠 뿐 결정은 기도 가운데 목사가 합니다.

---

### 세션 3 — 목표 설정: 3축 동시 설계 (11:40–12:40, 60분)

**① 미니 강의 (10분)**: 3축(영성/전도/양육)과 SMART, 그리고 "올해 안 할 것" 정하기.

**② 입력 (10분)**: 축별로 올해 바라는 변화를 자유롭게 서술.

**③ Claude 실행 (25분)** — `goal-architect` 스킬
- 진단의 병목을 근거로 축별 우선 목표 1~2개 추천
- 각 목표를 SMART로 정련, 기준선·목표치·신호 지표 설정
- 세 축 자원 충돌·과욕 경고

**④ 검토·확정 (15분)**: 목표치를 현실에 맞게 조정, "올해 유지/중단" 목록 확정.

**산출물**: 3축 목표·지표 한 장 요약표

### 점심 (12:40–13:40) — 식사 + 개인 기도/산책
오전 산출물(표어·목표)을 품고 조용히 기도하며 오후를 준비. 강제 토론 없이 쉼.

### 세션 4 — 설계: 설교·행사·캘린더 (13:40–15:20, 100분) ★목회계획의 심장

> 이 세션이 워크샵의 정점입니다. 성도가 1년 내내 실제로 만나는 것은 예산표가 아니라 **매주의 설교와 참여하는 행사**입니다. 표어를 강단과 행사로 번역하는 이 100분에 가장 많은 시간을 씁니다. 세 부분으로 진행합니다.

#### 4A — 52주 설교 계획 (13:40–14:20, 40분)

**① 미니 강의 (7분)**: 한 해를 하나의 영적 여정으로. 강해·주제·절기의 균형, 시리즈 단위 계획의 힘.

**② 입력 (8분)**: 표어·시즌제·절기·특별주일·설교 스타일 선호·작년 다룬 본문(기억나는 대로).

**③ Claude 실행 (18분)** — `sermon-planner-52` 스킬
- 표어를 분기 시리즈로 전개 → 주별 본문·제목·핵심 메시지·적용으로 **52주 전체 초안** 생성
- 절기·특별주일 자동 배치, 본문 중복·공백 경고, 강해/주제/절기 균형 점검

**④ 검토·확정 (7분)**: 1분기는 주별까지 확정, 2~4분기는 시리즈 주제까지. 어색한 본문 교체.

**산출물**: 2027 52주 설교 계획표 + 분기별 시리즈 개요

#### 4B — 연간 핵심 행사 기획 (14:20–14:55, 35분)

**① 미니 강의 (6분)**: 정기 행사 vs 핵심 행사. "이 행사가 표어의 무엇을 구현하는가?"가 없으면 정리.

**② 입력 (7분)**: 표어·3축 목표·작년 행사 효과 기억·올해 무게중심(영성/전도/공동체).

**③ Claude 실행 (15분)** — `signature-events` 스킬
- 표어·목표에서 핵심 행사 후보 3~5개 도출, 각 행사를 어느 축·목표를 섬기는지 명시
- 행사별 1페이지 기획안(목적·대상·시기·흐름·자원·성공 신호) + 행사–목표 연결 지도
- 설교 계획·시즌제와 정합성 점검(행사 주간 설교가 행사를 떠받치는가)

**④ 검토·확정 (7분)**: 목적 약한 행사 정리, 핵심 3~5개로 압축.

**산출물**: 연간 핵심 행사 기획안 + 행사–목표 연결 지도

#### 4C — 캘린더·실행계획 통합 (14:55–15:20, 25분)

**① Claude 실행 (18분)** — `ministry-calendar` + `action-planner` 스킬
- 52주 캘린더에 **설교 시리즈 + 핵심 행사 + 정기 행사 + 캠페인을 한 층으로 통합** 배치, 과부하 주간 경고
- 목표→분기 마일스톤, 부서별 실행계획표(목적·시기·담당·자원)
- **설교–행사–사역 3중 정합성 점검**

**② 검토·확정 (7분)**: 무리한 주간 재배치, 담당 미정 항목 표시.

**산출물**: 설교·행사 통합 연간 사역 캘린더 + 부서별 실행계획표

> 진행 팁: 4A·4B에서 Claude가 초안을 빠르게 생성하므로 목사는 "백지에서 짜는" 부담 없이 **검토·교정**에 집중합니다. 외부 컨설턴트라면 며칠 걸릴 52주 설교 초안이 분 단위로 나오는 것이 이 세션의 핵심 가치입니다.

### 세션 5 — 자원 정렬: 사람·예산·시간 (15:30–16:10, 40분)

**① 미니 강의 (6분)**: 더하기 전에 빼기. 담임목사 시간이 최대 제약.

**② 회상 입력 (10분)**: 핵심 일꾼을 이름으로 떠올리며 은사·여력, 예산은 결산 파일 없이 **비율 감각과 증감 방향**으로(예: 선교 10%→15%).

**③ Claude 실행 (16분)** — `resource-aligner` 스킬
- 실행계획 자원 수요 vs 가용 갭 분석
- 3축·부서별 예산 재배분안 + 작년 대비 시각화
- 리더 공백 식별·양성 필요 인원
- 담임목사 주간 시간 배분 시뮬레이션

**④ 검토·확정 (8분)**: "이걸 위해 무엇을 멈출까" 결정.

**산출물**: 예산 배분안 + 조직·담당 배치표 + 목사 시간 가이드

### 세션 6 — 점검 리듬 설계 (16:10–16:40, 30분)

## 워크샵 후 보강 트랙 (옵션 2) — D+1 ~ D+14

워크샵 당일(옵션 1)은 기억만으로 완결된 계획을 만듭니다. 그러나 진짜 경쟁력은 그 계획이 교회로 돌아가 **실제 자료를 끌어와 스스로 보정되는** 데 있습니다. 자료 수집의 책임을 워크샵 *전*이 아니라 *후*로 옮긴 것이 핵심입니다 — 빈손으로 와서 계획을 얻고, 그 계획이 자료를 부릅니다.

**진행 방식 (목사가 교회에서 혼자, 약 30~60분)**
- 워크샵에서 받은 *옵션 2 안내문*과 계획서를 연다
- 교회에 있는 자료를 **있는 만큼만** 작업 폴더에 업로드(주보·결산서·교적부 일부 등 — 전부 갖출 필요 없음)
- `plan-reinforce` 스킬 호출: 진단에서 '신뢰 하'로 표시됐던 가정 항목부터 실측으로 교체
- Claude가 추정값 vs 실측값을 비교해 어긋난 곳을 강조하고, 진단·목표·예산을 자동 갱신
- 보정된 *신년 목회계획서 v2* 확보

**운영 지원 (선택)**
- D+7 즈음 운영팀이 리마인드 메시지 발송("자료 보강하셨나요?")
- 막히는 목사를 위한 30분 온라인 보강 클리닉 1회
- 보강 트랙을 **분기 점검(단계 6)의 첫 사이클**로 연결 — 일회성 숙제가 아니라 살아 있는 리듬의 시작

> 자료가 끝내 부족해도 괜찮습니다. 확인된 만큼만 확정하고, 나머지는 분기 점검에서 채웁니다. 옵션 2는 의무가 아니라 계획을 80%에서 95%로 끌어올리는 보너스 트랙입니다.

## Claude Code 역량을 "전폭 활용"하는 포인트 정리

0. **자료 없이 진단**(최대 차별점): 회상 인터뷰로 목사의 기억을 정량 진단으로 재구성 — 빈손으로 와도 컨설팅급 진단표가 나온다. 외부 컨설턴트가 못 하는 일.
1. **즉시 시각화**: 입력 즉시 차트·대시보드 — 컨설턴트가 며칠 걸려 만드는 진단표를 분 단위로.
2. **병렬 옵션 생성**: 표어·목표를 여러 안으로 동시에 펼쳐 비교·분별을 도움.
3. **교차 정합성 점검**: 캘린더 과부하, 예산-목표 불일치, 자원 갭을 자동 경고.
4. **멀티 산출물 동시 생성**: 같은 계획을 Word·PPT·한장 요약 등 청중별로 한 번에.
5. **스케줄 자동화**: 분기마다 지표를 모아 자동 리포트 — 계획을 살아 있게 유지.
6. **반복 가능성**: 내년에도 같은 스킬로 30% 시간에 갱신 — 첫해의 투자, 매년의 수익.
7. **자기보정 계획**(옵션 2): 귀가 후 실제 자료를 업로드하면 추정치가 실측으로 자동 교체·갱신 — 계획이 80%에서 95%로 스스로 자란다.
