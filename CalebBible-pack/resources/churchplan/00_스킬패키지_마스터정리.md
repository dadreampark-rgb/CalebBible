# PastorPlan 2027 — 신년 목회계획 Claude 스킬 패키지 (마스터 정리본)

> 이 문서는 지금까지 설계한 모든 내용을 한 곳에 모은 **완성 정리본**입니다. 각 스킬의 이름·목적·기능·입력·출력물과, 스킬들이 실제로 어떤 순서로 작동하는지를 빠짐없이 정리했습니다.

---

## 1. 패키지 개요

**무엇인가**: 담임목사가 워크샵 8시간 동안 직접 컨설팅급 2027 신년 목회계획을 완성하도록 돕는 Claude 스킬 묶음(플러그인).

**구성**: 회상 엔진 1 + 핵심 스킬 10 + 지원 스킬 1 + 보강 스킬 1 = **자체 스킬 13개**, 외부 연동 스킬 1개(`grill-me-docs`), 출력용 코어 스킬 4개(`docx`·`pptx`·`xlsx`·`pdf`).

**세 가지 설계 원칙**
1. **자료 없이 작동한다.** 목사는 통계·예산서를 가져오지 않는다. 모든 스킬은 파일이 아니라 **기억·추정·범위값**을 입력으로 받는다.
2. **설교와 행사가 심장이다.** 성도가 1년 내내 만나는 것은 예산표가 아니라 매주 설교와 핵심 행사다. 단계 4의 두 스킬이 패키지의 중심이다.
3. **계획은 살아 움직인다.** 워크샵에서 기억으로 80% 계획을 세우고(옵션 1), 귀가 후 실제 자료로 95%로 보강한다(옵션 2).

## 3. 사용 순서 (이게 핵심입니다)

### 옵션 1 — 워크샵 당일 (자료 없이, 기억만으로)

스킬은 다음 순서로 **앞 스킬의 출력이 뒤 스킬의 입력이 되는 사슬**로 작동합니다.

```
[0] guided-recall (+grill-me-docs)
        │  목사의 기억을 캐물어 → 회상 데이터셋
        ▼
[1] diagnostics
        │  회상 데이터 → 진단 대시보드 + 강점/시급 과제
        ▼
[2] vision-discernment
        │  진단 + 기도 키워드 → 올해 표어 + 방향 선언문
        ▼
[3] goal-architect
        │  표어 → 영성·전도·양육 3축 목표·지표
        ▼
   ┌────── 단계 4: 설계 (심장) ──────┐
[4] sermon-planner-52   표어·시즌 → 52주 설교 계획표
[5] signature-events    표어·목표 → 핵심 행사 3~5개
[6] ministry-calendar   설교+행사+사역 → 통합 52주 달력
[7] action-planner      목표 → 부서별 실행계획표
   └──────────────────────────────────┘
        ▼
[8] resource-aligner
        │  실행계획 → 예산·조직·목사 시간 배분
        ▼
[9] review-rhythm
        │  3축 지표 → 분기 점검표 + 자동 리포트 구조
        ▼
[10] plan-compiler
        │  위 전부 → 목회계획서 + 발표 슬라이드 + 비전 한장
        ▼
   ✅ 완성된 2027 목회계획 패키지 (손에 들고 귀가)

[11] prayer-scripture-kit — 영성 축 보강용. 단계 3~4 사이 또는 이후 필요 시 호출(순서 자유).
```

**순서의 논리**: 진단(현실)→분별(방향)→목표(무엇을)→설계(설교·행사·달력)→정렬(사람·돈)→점검(지속)→통합(문서화). 방향을 정하기 전에 설교를 짜지 않고, 목표 없이 행사를 만들지 않는다. 각 스킬은 반드시 **앞 단계의 확정 산출물**을 입력으로 받는다.

### 옵션 2 — 워크샵 후 1~2주 (교회에서, 실제 자료로)

```
[12] plan-reinforce
        │  옵션1 산출물 + 교회 실제 자료(있는 만큼)
        │  → "확실치 않음" 항목을 실측으로 교체
        ▼
   ✅ 보정된 확정 계획서 v2  →  이후 [9] review-rhythm의 분기 점검으로 연결
```

## 4. 스킬별 완전 명세

각 스킬은 **목적 / 트리거 / 입력 / 기능(처리) / 출력물 / 신학적 가드레일**로 정리합니다.

---

### [0] `guided-recall` (+ `grill-me-docs`) — 회상 인터뷰 엔진
*패키지의 출발점. 자료 없는 진단을 가능하게 하는 핵심.*

- **목적**: 교회 자료가 전혀 없는 목사에게서 대화형 회상 인터뷰로 지난 1년의 진단 데이터를 끌어낸다.
- **두 엔진 분리 구조**:
  - `grill-me-docs`(외부 연동, *질문* 담당): 적응형 꼬리질문·재질문을 연쇄로 던져 막연한 기억을 구체적 사건·수치로 인출. 인터뷰의 깊이 담당.
  - `guided-recall`(본 패키지, *구조화* 담당): 그 답변을 범위 추정치·신뢰수준·8영역 점수로 정규화해 다음 스킬이 쓸 표준 데이터셋으로 변환.
- **트리거**: 진단 세션 시작, "자료가 없어요", "기억나는 대로".
- **입력**: 목사의 기억뿐 (파일 불필요).
- **기능**: ① 달력 걷기(1→12월 순회로 최신 편향 차단) ② 사람 회상(이름·얼굴로) ③ 범위 추정 유도 + 신뢰수준(상/중/하) ④ 삼각 검증(긍정·부정·근거 3방향 재질문) ⑤ 건강 8영역 1~5점화 ⑥ 표준 데이터셋 구조화.
- **출력물**: 구조화된 기억 데이터셋(추정치+신뢰수준), 작년 12개월 회상 타임라인.
- **가드레일**: 자료 없음을 부끄럽게 하지 않는 따뜻한 톤. 집요하되 추궁이 아닌 목양적 동행. 신뢰 '하'는 단정 않고 가정으로 표시.

### [1] `diagnostics` — 교회 현황 진단

- **목적**: 회상 데이터를 컨설팅급 진단 대시보드로 변환(추정치 기반).
- **트리거**: "교회 현황 진단", "작년 리뷰".
- **입력**: `guided-recall`의 회상 데이터셋(있으면 실제 자료 보조 병합).
- **기능**: 추정 범위·신뢰수준 시각화, 추이 방향(↑↓→) 그래프, 깔때기(전도→정착→양육→리더) 병목 식별, 건강 8영역 그림표, 작년 다짐 대비 실행 대조, Top 3 강점/시급 과제 + "귀가 후 확인할 항목" 목록.
- **출력물**: 한 장 진단 대시보드(html, 신뢰수준 표기) + 정리표(xlsx).
- **가드레일**: 추정치를 확정처럼 보이지 않게 구분. 숫자를 정죄가 아닌 돌봄의 신호로. "성장=성공" 강요 금지.

### [2] `vision-discernment` — 표어·방향 분별

- **목적**: 올해 표어·본문 후보를 펼쳐 분별을 돕는다(결정은 목사).
- **트리거**: "올해 표어", "목회 방향", "비전 선언문".
- **입력**: 진단 결과 + 기도 키워드·본문 메모 + 교회 상황.
- **기능**: 영성형/전도형/공동체형 3계열 표어 후보 전개, 각 후보의 핵심 본문·간략 주해·적용, 표어→3축 연결 논리 점검 및 추상도 경고.
- **출력물**: 표어 후보 비교표 + 확정 방향 선언문 1단락(md).
- **가드레일**: 선택지만 제시, 방향 단정 금지. "기도 가운데 분별하라" 안내 명시.

### [3] `goal-architect` — 3축 목표 설계

- **목적**: 표어를 영성·전도·양육 3축의 측정 가능한 목표로 번역.
- **트리거**: "목표 설정", "올해 목표", "3축 목표".
- **입력**: 표어·방향 + 진단 병목 + 축별 희망 변화.
- **기능**: 병목 근거로 축별 우선 목표 1~2개 추천, 각 목표를 구체·측정 가능하게 다듬고 기준선/목표치/신호 지표 설정, 자원 충돌·과욕 경고, "올해 유지/중단" 목록 도출.
- **출력물**: 3축 목표·지표 요약표(md + xlsx 점검표 씨앗).
- **가드레일**: 영적 목표를 숫자로 환원하지 않게 정성 목표를 늘 정량 지표와 한 쌍으로. 무리한 목표치 경고.

### [4] `sermon-planner-52` — 52주 설교 계획 ★심장(1)

- **목적**: 표어와 시즌을 1년 52주의 본문·제목·메시지로 완성. 한 해 전체를 하나의 영적 여정으로.
- **트리거**: "설교 계획", "52주 설교", "연간 본문", "강해 시리즈".
- **입력**: 확정 표어·핵심 본문·방향 선언문(단계 2) + 시즌 골격 + 절기·특별주일 + 설교 스타일 선호 + 작년 다룬 본문(기억나는 대로).
- **기능**: 표어를 분기 설교 시리즈로 전개 → 주별 본문·제목·핵심 메시지·적용으로 52주 전체 초안 생성, 절기·특별주일 자동 배치, 강해/주제/절기 균형 점검, 본문 중복·핵심 교리 공백 경고, 시리즈 서사 점검.
- **출력물**: 2027 52주 설교 계획표(주차·날짜·절기·시리즈·본문·제목·핵심 메시지·적용, xlsx) + 분기별 시리즈 개요(docx).
- **유연성**: 1분기는 주별까지, 2~4분기는 시리즈 주제까지만 확정하는 '롤링' 모드.
- **가드레일**: 본문 선택·해석 최종 권한은 목사. Claude는 초안 생성기이지 주해 대행자가 아님. 성령의 인도·회중 형편에 따른 수정 여지 항상 열어 둠.

### [5] `signature-events` — 연간 핵심 행사 기획 ★심장(2)

- **목적**: 표어·철학을 체험으로 구현하는 핵심 행사 3~5개를 기획.
- **트리거**: "행사 기획", "핵심 행사", "전도 축제 기획".
- **입력**: 표어·방향 선언문·3축 목표(단계 2~3) + 작년 행사 효과 기억 + 올해 무게중심.
- **기능**: 정기 행사(절기·연례)와 핵심 행사(전략적) 구분, 표어·목표에서 핵심 행사 후보 도출, 각 행사를 *어느 축·목표를 섬기는가*로 명시, 행사별 1페이지 기획안 작성, 설교 계획·시즌과 정합성 점검, 과밀·자원 충돌 경고.
- **출력물**: 연간 핵심 행사 기획안 3~5개(각 1페이지, docx) + 행사–목표 연결 지도(xlsx).
- **가드레일**: "작년에 했으니"를 경계. 목적 없는 행사 정리 제안. 행사 수보다 깊이. 작은 교회 인력 한계 고려.

### [6] `ministry-calendar` — 연간 사역 캘린더 (통합 레이어)

- **목적**: 설교 시리즈·핵심 행사·정기 행사·캠페인·목표 마일스톤을 한 달력에 통합하고 과부하 경고.
- **트리거**: "연간 캘린더", "통합 캘린더", "절기 배치".
- **입력**: 52주 설교 계획표(#4), 핵심 행사 기획안(#5), 절기·지역/학사 일정·목사 개인 일정, 목표 마일스톤.
- **기능**: 52주 격자 통합 배치, 시즌 정렬(1Q 영성/2Q 전도/3Q 양육/4Q 감사 등), 설교–행사–사역 3중 정합성 점검, 행사 밀집 주간 경고, 목사 휴식·안식 주간 보호.
- **출력물**: 설교·행사 통합 연간 캘린더(분기·월·주 보기, html + xlsx).
- **가드레일**: 목회자·봉사자 소진 방지를 위해 연속 고강도 주간 자동 표시.

### [7] `action-planner` — 부서별 실행계획

- **목적**: 각 목표를 담당·시기·자원이 명시된 행동으로 분해.
- **트리거**: "실행계획", "부서별 계획", "액션 플랜".
- **입력**: 3축 목표, 캘린더, 부서·담당 구조.
- **기능**: 목표→분기 마일스톤→월별 행동 분해, 부서별(예배·교육·전도·선교·양육·행정) 표 생성(목적·시기·담당·자원), 담당/자원 미정 항목 자동 플래그.
- **출력물**: 부서별 실행계획표(xlsx).
- **가드레일**: "언제·누가" 공백을 강제로 드러내 실행 가능성 확보.

### [8] `resource-aligner` — 자원 정렬(예산·조직·시간)

- **목적**: 계획에 사람·돈·시간을 붙이고 부족분을 진단.
- **트리거**: "예산 배분", "조직 정렬", "목사 시간 배분".
- **입력**: 기억으로 떠올린 핵심 일꾼·은사·여력, 예산의 **비율 감각과 증감 방향**(절대 금액 불요), 머릿속 조직도, 실행계획.
- **기능**: 실행계획 자원 수요 vs 가용 갭 분석, 3축·부서별 예산 재배분안(비율 기반)·증감 시각화, 리더 공백·양성 필요 인원 식별, 담임목사 주간 시간 배분 시뮬레이션.
- **출력물**: 예산 배분안 + 조직 배치표 + 목사 시간 가이드(xlsx).
- **가드레일**: "더하기 전 빼기" 강제. 담임목사 영적·체력 지속가능성을 자원으로 명시.

### [9] `review-rhythm` — 점검 리듬·자동 리포트

- **목적**: 계획이 1년 내내 살아 움직이도록 점검 구조와 자동화를 설계.
- **트리거**: "점검 계획", "분기 리뷰", "스코어카드", "자동 리포트".
- **입력**: 3축 지표·목표치.
- **기능**: 분기 스코어카드(신호등) + 월간 1페이지 점검표 생성, 지표 빨강 시 대응 시나리오, (선택) 분기마다 지표 수집·리포트 자동 발송 스케줄 구성.
- **출력물**: 점검 스코어카드·월간 점검표(html + xlsx), 연간 점검 일정.
- **가드레일**: 점검을 성과 압박이 아닌 돌봄으로 프레이밍. 반기 공식 수정일 못박기 안내.

### [10] `plan-compiler` — 계획서·발표자료 통합 생성

- **목적**: 모든 산출물을 청중별 문서로 묶어 최종 패키지 완성.
- **트리거**: "계획서 만들어", "발표 슬라이드", "비전 한장", "통합".
- **입력**: 전 산출물(52주 설교 계획표·핵심 행사 기획안 포함), 교회명·로고·톤.
- **기능**: 목회계획서 본문 통합(설교·행사를 핵심 장으로), 당회/제직회용 요약 슬라이드 10장, 성도용 비전 한 장, 표어·디자인 톤 일관성 적용.
- **출력물**: 계획서 본문(docx/pdf) + 발표 슬라이드(pptx) + 비전 한 장.
- **의존 스킬**: 코어 출력 스킬 비의존 — `python-docx`·`python-pptx`·`weasyprint`로 자기완결 렌더(docx·pptx·pdf·html).

### [11] `prayer-scripture-kit` — 영성 실천 키트 (지원)

- **목적**: 영성 축 목표를 회중이 실제로 쓰는 도구로 구체화.
- **트리거**: "성경통독표", "기도제목", "가정예배", "새벽기도 시즌".
- **기능**: 연간 성경통독 트랙, 월별 전교인 기도제목, 가정예배 가이드, 새벽기도 시즌 안내문 제작.
- **출력물**: 인쇄용 키트(docx).
- **가드레일**: 율법적 압박이 아닌 은혜의 초청 톤.

### [12] `plan-reinforce` — 귀가 후 자료 보강 (옵션 2) ★다리

- **목적**: 기억으로 세운 계획을, 교회에서 실제 자료를 형편껏 올려 실측으로 보정·확정.
- **트리거**: 워크샵 후 "자료 보강", "실제 수치로 업데이트", "주보/결산서 올렸어요".
- **입력**: 옵션 1 산출물 + 교회 실제 자료(주보·결산서·교적부·회의록 — 있는 것만, 순서 무관).
- **기능**: 자료에서 출석·헌금·등록·행사 데이터 추출, 신뢰 '하' 가정 항목 우선 실측 교체, 추정 범위를 실제 값으로 좁힘, 진단·목표·예산 자동 갱신("추정→실측" 이력 표시), 새 병목 시 조정 제안, 미확인 항목은 `review-rhythm` 분기 추적으로 이월.
- **출력물**: 보정 진단 대시보드(추정 vs 실측 비교, xlsx) + 신년 목회계획서 v2(docx).
- **가드레일**: 있는 만큼만 보정, 부족 비난 금지. 추정·실측 시각 구분으로 확정 범위 투명화. "계획이 스스로 자란다"는 격려 틀.

## 5. 외부·코어 의존 스킬

- **`grill-me-docs`** (외부 연동, [0]의 질문 엔진): 적응형 심문으로 기억을 인출. **현재 미설치·레지스트리 미확인.** 두 경로 중 택1 — ① 마켓플레이스/사내 저장소에서 설치, ② `skill-creator`로 동등 스킬 자체 제작(핵심: 끝없는 꼬리질문 + 다각도 재질문 + 모호한 답 좁히기). 어느 쪽이든 `guided-recall`은 구조화에 집중하고 질문은 이 스킬에 위임.
- **`docx` / `pptx` / `xlsx` / `pdf`** (코어 출력 스킬): 패키지 일부 스킬이 최종 문서·표·슬라이드·PDF를 만들 때 호출. 단 [10] `plan-compiler`는 예외 — 코어 출력 스킬에 의존하지 않고 `python-docx`·`python-pptx`·`weasyprint`로 자기완결 렌더한다.

## 6. 폐기·격상 이력 (설계 변경 기록)

- **폐기 — `data-intake`**: '사전 과제 파일 정규화' 스킬. 참가자가 자료를 안 가져오는 현실 때문에 폐기. 진단 출발점은 `guided-recall`이 대체. 단 파일 처리 기능은 사라진 게 아니라 워크샵 *후* 시점의 `plan-reinforce`(옵션 2)로 이동·부활.
- **격상 — `sermon-roadmap` → `sermon-planner-52`**: 시리즈 골격만 제안하던 '지원' 스킬을, 52주 전체를 주별까지 생성하는 '핵심·심장' 스킬로 격상.
- **신설 — `signature-events`**: 표어·철학 기반 핵심 행사 기획 스킬 신설(핵심·심장).
- **신설 — `plan-reinforce`**: 옵션 2(귀가 후 보강) 전담 스킬 신설.
- **연동 — `grill-me-docs`**: 옵션 1 회상 인터뷰의 질문 엔진으로 외부 스킬 연동.

## 7. 제작·배포 가이드

**구축 우선순위**
1. **1차 (필수 경로 + 심장)**: `guided-recall` → `diagnostics` → `vision-discernment` → `goal-architect` → **`sermon-planner-52` → `signature-events`** → `action-planner` → `plan-compiler`. 이 사슬만으로 "기억→진단→표어→목표→설교·행사→계획→문서"가 완결된다. `guided-recall`과 두 심장 스킬을 가장 먼저, 가장 정교하게 제작.
2. **2차 (완성도)**: `ministry-calendar`, `resource-aligner`, `review-rhythm`, `plan-reinforce`.
3. **3차 (부가가치)**: `prayer-scripture-kit`.

**배포**: 13개 스킬을 플러그인 "PastorPlan 2027"로 묶고 코어 출력 스킬에 의존하도록 구성. 진단 질문 세트·워크북·'12개월 빈 타임라인' 인쇄물·디자인 톤 가이드를 동봉. 워크샵 전 좌석마다 일괄 설치(+`grill-me-docs` 또는 대체 스킬 확인).

**검증**: 각 스킬은 `skill-creator`로 제작하고 샘플 교회 데이터로 평가(eval)를 돌려 트리거 정확도·출력 품질을 확인한 뒤 포함.

**재사용성**: 동일 패키지로 내년 갱신·타 교회 적용 가능. 첫해 구축이 매년의 자산.
