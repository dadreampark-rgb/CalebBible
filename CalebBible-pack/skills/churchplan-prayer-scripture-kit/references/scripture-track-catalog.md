# 영성 키트 카탈로그 — 표준 통독 트랙·가정예배 양식·새벽 시즌 패턴

> #11 하위 스킬이 공유하는 영성 도구 패턴. 콘텐츠를 *지어내는* 카탈로그가 아니라, 정경 권·장 데이터(bible_validator BOOK_CHAPTERS)로 *결정론 배정*할 표준 틀이다. 없는 권·장을 만들지 않는다.

## 1. 표준 통독 트랙 (목사 선택 — 결정론 배정)
정경 66권 = 1189장(구약 39권 929장 + 신약 27권 260장). scripture-track-builder의 `scripts/allocate_track.py`가 권·장 순서로 일별 배정을 계산한다.

| 트랙 | 범위 | 분량 기준 | 비고 |
|---|---|---|---|
| **1년 통독** | 창세기→요한계시록 1189장 | 365일 ≈ 3~4장/일 | 가장 일반적 |
| **신약 1년** | 마태복음→요한계시록 260장 | 365일 ≈ 5~6절/일(느린 묵상) | 처음 통독하는 회중 |
| **맥체인(McCheyne)** | 구약 1독 + 신약·시편 2독 | 4 본문/일 | 전통 트랙(가정+개인) |
| **시편·잠언** | 시편 150편 + 잠언 31장 | 월별 반복(잠언 31장=한 달) | 기도·지혜 집중 |
| **시즌 통독** | 절기 연계(사순절 복음서 등) | 시즌 기간 | 표어·절기와 묶음 |

- 트랙 선택은 **목사 HITL**. 트랙 범위의 책이름·장은 bible_validator로 실재 검증.
- `allocate_track.py`가 BOOK_CHAPTERS로 일별 권·장을 결정론 계산(권 경계 존중·장 누락/중복 0). fidelity-guard가 각 portion의 장·절·장범위 끝을 정경 범위로 재검증.
- **결정론 배정 범위**: `allocate_track.py`는 선형 단일 흐름 트랙 — **1년 통독·신약 1년·시편·잠언** — 을 결정론 배정한다. **맥체인**(4 본문/일·OT 1독+NT·시편 2독의 다중 흐름)과 **시즌 통독**(절기·기간 의존)은 선형 배정이 아니므로 LLM이 정경 권·장으로 구성하고(schedule은 요약 형태 가능) fidelity-guard·렌더러가 각 portion의 정경 실재를 동일하게 재검증한다(스키마 line 43 "결정론 생성 또는 요약").

## 2. 통독표 — 은혜의 융통성 (보완B — 율법화 차단)
통독은 본질이 "매일"이라 가장 율법화되기 쉽다. 통독표에 다음을 *내장*한다(`grace_frame`):
- **"낙오는 실패가 아닙니다."** 빠진 날은 죄가 아니다.
- **"언제든 다시 합류하세요."** 못 따라가면 오늘부터 다시.
- **"읽은 만큼이 은혜입니다."** 완주율은 자기 격려용일 뿐 채찍이 아니다.
- 자기 점검 칸(`checkbox`)은 *기쁨의 표시*지 감시가 아니다.
- 금지 어휘: 매일 …해야·완주 못하면·반드시·의무·죄책·게으름·빠지면 안 된다.

## 3. 월별 전교인 기도제목 패턴
"온 교회가 같은 제목으로 함께 기도하는 자리"(강제 아님).
- 각 달 2~4개. 출처: vision 표어·goals 영성 목표·교회 형편(목사 입력).
- 절기·시즌과 자연스럽게 묶기(1월 새해·부활절·맥추·추수감사·성탄).
- 지어내기 금지: 없는 약속·응답을 단언하지 않는다(전사).

## 4. 가정예배 가이드 양식 (1:1 말씀나눔 — 보완A)
01 라인 159 "1:1 말씀나눔 참여 가정 수" — 혼자 읽기가 아니라 *가정·짝이 함께 나누는* 양식.
- 순서: 찬송 → 본문 읽기(실재) → **묵상 나눔**(질문으로 서로 나눔) → 함께 기도.
- 본문은 통독/설교/표어와 연계(실재 권·장).
- 묵상 질문은 본문에서 길어 올린다(곡해·아전인수 금지).
- 짧고 반복 가능하게(가정이 매주 부담 없이).

## 5. 새벽기도 시즌 패턴 (은혜의 초청)
"함께 깨어 기도하는 시즌"(상시 강제가 아니라 *시즌제*).
- 시즌 예: 사순절 특별새벽·맥추 40일·송구영신·표어 집중 기간.
- 각 시즌: 이름·기간·주제(표어 연계)·본문(실재).
- 안내문 톤: 초청("함께 깨어 기도합시다")이지 의무 부과가 아니다.
- `serves_indicator`: 새벽기도 평균 참여(영성 신호 — 격려용).
