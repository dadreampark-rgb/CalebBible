# 자료 보강 카탈로그 — 자료 유형별 추출 매핑·추정→실측 이력·이월 패턴

> #12 하위 스킬이 공유하는 보강 패턴. 자료를 *지어내는* 카탈로그가 아니라, 실제 자료에서 *무엇을 읽을 수 있는지*의 매핑과 추정→실측 이력의 양식이다. 자료에 없는 값을 만들지 않는다.

## 1. 자료 유형별 추출 가능 데이터 (있는 것만)
폐기된 data-intake의 파일 처리 기능이 워크샵 *후* 시점으로 부활(00 라인 234).

| 자료 | 읽을 수 있는 데이터 | 갱신 대상 |
|---|---|---|
| **주보** | 주일·새벽 출석·헌금·광고(행사) | diagnosis 출석/헌금·review 새벽 참여 |
| **결산서·재정보고** | 수입·지출·항목별 비율 | resource 예산 current_by_function·diagnosis 헌금 |
| **교적부·새가족 명부** | 등록·정착·전출입·세례 | diagnosis 깔때기(유입→정착)·goals 정착률 |
| **회의록(당회·제직회)** | 결정 사항·행사 실시 여부·결산 | events 실시 여부·action 진척 |
| **출석 체크·소그룹 명부** | 소그룹·양육 참여 | diagnosis 양육·goals 양육 지표 |

- **출처 명시 필수**: 추출값마다 `source_material`(어느 자료)·`source_detail`(어느 부분). 출처 없는 값은 실측 아님.
- **있는 것만**: 자료가 일부만 있어도 작동. 없는 데이터는 추정 유지 또는 이월.
- 결정론 파싱이 불가능한 형식(스캔 PDF·이미지·hwp)은 AI가 읽되 *목사 확인(HITL)* 을 거친다.

## 2. 추정→실측 이력 양식 (추정을 지우지 않는다)
실측 교체는 추정을 *덮어쓰는* 게 아니라 *나란히 놓는* 것이다.

```
estimate:      120~140명 (신뢰 중)        ← 워크샵에서 기억으로
actual:        131명                       ← 자료에서 실측
actual_source: 2026 12월 주보 4주 평균     ← 근거(필수)
delta:         범위 내(중앙값 근접)         ← 추정이 맞았나
status:        실측교체                     ← 실측교체 | 추정유지 | 이월
new_confidence: 상                         ← 실측 후 신뢰 갱신
```
- **3 status**: `실측교체`(자료로 확인) / `추정유지`(자료 없음·당분간 추정) / `이월`(#9 분기 추적).
- 추정과 실측의 차이(`delta`)를 늘 비춘다 — 확정 범위가 얼마나 또렷해졌는지.

## 3. 어긋남(mismatch) → 새 병목 (강조)
추정과 실측이 *유의하게 다르면* 단순 교체가 아니라 **새 병목 신호**다(02 라인 253 "어긋난 곳을 강조").
- 예: 추정 "정착 5~7가정" → 실측 "2가정" = `mismatch:true` → plan-updater의 새 병목 조정 제안.
- mismatch 항목은 강조하고, 목표·예산·행동 조정으로 연결한다(기능⑤).
- 추정이 맞은 항목(범위 내)은 조용히 확정.

## 4. 이월 패턴 (#9 분기 점검 첫 사이클)
자료가 끝내 부족해도 괜찮다 — "확인된 만큼만 확정, 나머지는 분기 점검에서"(02 라인 261).
- 미확인 항목 → `carryovers`(reason·to:#9 review-rhythm).
- 실측 baseline → `to_review.updated_baselines`(#9 다음 사이클이 신뢰 '상'으로 점검).
- #12는 일회성 숙제가 아니라 **#9의 첫 사이클** — 살아 있는 리듬의 시작(02 라인 259).

## 5. "계획이 스스로 자란다" 격려 틀
- 자료 부족을 비난하지 않는다("이것밖에·왜 없나" 금지).
- 옵션2는 의무가 아니라 80%→95% 보너스 트랙(02 라인 261).
- 톤: "계획이 자료를 만나 또렷해졌습니다" — 성장의 언어.
