# 자원 정렬 카탈로그 — 예산 차원·시간 블록·여력 등급 (단일 진실)

> budget-allocator·pastor-time-guard·org-mapper·demand-estimator가 공유한다. 박사님 프레임워크(01 단계5)의 자원 모델을 적용한다. **모두 자료 없이 기억·비율·범위로 작동한다.**

## 1. 예산 차원 (보완1 — 2층 구조)

01은 두 관점을 함께 쓴다. 둘을 구분해 박사님 "3축·부서별" 의도를 보존한다.

### (a) 기능별 현황 — `current_by_function` (목사 기억, 01 라인 275)
목사가 기억하는 대략 비율. 절대 금액 불요.
| 기능 | 설명 |
|---|---|
| 인건비 | 사례비·직원 |
| 운영 | 시설·관리·공과금 |
| 사역 | 예배·교육·전도·양육 활동비 |
| 선교 | 선교지·지역 섬김·후원 |

### (b) 전략별 재배분 — `realloc_by_strategy` (01 라인 282)
표어·목표를 반영해 **3축**(영성·전도·양육) 또는 **부서별**로 증감. 각 항목에 `dimension`(3축|부서)·`last`·`this`·`change`(▲▼)·`rationale`.
- 예: "선교 10%→15%(▲5) — 선교 결연 목표" / "전도 ▲ — 정착 병목·표어".
- **절대 금액 금지**: 모두 % 또는 증감 방향. 실제 금액은 재정 담당과 확정.

## 2. 담임 주간 시간 블록 (pastor-time-guard, 01 라인 284)

"주간 시간 예산" — 담임목사의 한 주를 상대 비중으로 배분. **기도·쉼은 보호 자원(`protected:true`).**

| 블록 | 설명 | 보호 |
|---|---|---|
| 설교 준비 | #4 52주 강단 — 가장 큰 블록 | |
| 심방·돌봄 | 양 떼 돌봄 | |
| 행정·회의 | 운영 | |
| 기도·영성 | 목자 자신의 경건 | ✅ protected |
| 쉼·안식 | 회복·가정(#6 rest_plan 연계) | ✅ protected |

- 설교+행사 부하기(절기·고강도 주간)엔 심방·행정이 압박된다 → `warning`으로 위임/축소 제안.
- **100% 사역으로 채우지 않는다.** 기도·쉼이 없으면 fidelity-guard가 위반(소진 방지·가드레일 ④).

## 3. 일꾼 여력 등급 (org-mapper·demand-estimator, 01 라인 274)

목사가 이름으로 떠올린 일꾼의 여력. #7 중복배정 카운트의 *질적 판단* 단계.
| capacity | 의미 | 새 배정 |
|---|---|---|
| 여유 | 더 맡길 여력 있음 | 가능 |
| 보통 | 현행 적정 | 신중 |
| 지침 | 이미 지침 | 새 배정 시 `load:"과중"` 경고 — 갈지 않는다 |

- `org_plan.leader_gaps`는 **#7 `gaps`(담당미정)**에서 온다(보완2 — `from_action_gap`으로 추적).
- 리더 공백 → `develop_needed`(양성 필요 인원). 작은 교회는 양성도 시간 자원이 든다.

## 4. 더하기 전 빼기 (demand-estimator, 01 라인 291)

새 자원 수요(증액·증원·시간 추가)가 나오면 **반드시 빼기 후보**를 함께 낸다.
- `demand_gaps[].subtract_candidate`: 이 갭을 메울 빼기(#3 `stop_list` 상속 우선).
- `subtractions[]`: 최종 빼기 목록(HITL에서 목사 확정).
- "이 목표를 위해 무엇을 멈출 것인가"가 #8 HITL의 핵심 질문.

## 5. 경계 — #8이 하지 않는 것
- **지표 점검 리듬·스코어카드는 #9(review-rhythm).** #8은 자원을 *배분*하고 부족을 *진단*만 한다.
- **부서별 행동 분해·담당 배정은 #7(action-planner).** #8은 그 담당의 *여력*과 *예산·시간*을 본다.
- **절대 금액 확정은 재정 담당(워크샵 후).** #8은 비율·증감 방향까지.
