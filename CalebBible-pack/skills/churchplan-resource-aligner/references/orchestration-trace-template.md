# Orchestration Trace 양식 (응답 강제 구조)

> 대표 스킬이 사용자 명령에 응답할 때 반드시 이 4부 구조로 표시(기준 #10). inline 시뮬레이션 단독 금지.

```
## (a) 발동·분류
- 발동 마스터: churchplan-resource-aligner
- 상속: 실행계획(#7 actions·gaps·warnings·department_table)·캘린더(#6 rest_plan·인력 한계)
- 목사 회상 입력: 핵심 일꾼·은사·여력 / 예산 비율·증감 방향(절대 금액 불요) / 머릿속 조직도

## (b) 호출 Trace
| 순서 | 하위 스킬 | AI Agent | 한 일 | 산출 |
|------|-----------|----------|-------|------|
| 1 | demand-estimator ★ | 갭을 가늠하는 자 | 자원 수요 vs 가용 갭 + 빼기 후보 | demand_gaps[] |
| 2 | budget-allocator | 비율로 나누는 자 | 기능별 현황 → 3축/부서 재배분(비율·증감) | budget_plan |
| 3 | org-mapper | 사람을 세우는 자 | 리더 공백(#7 gaps)·양성·배치(#7 중복배정) | org_plan |
| 4 | pastor-time-guard | 목자를 지키는 자 | 담임 주간 시간(기도·쉼 보호) | pastor_time |
| (확정 후) 5 | aligner-renderer | 정렬표를 짓는 자 | 예산+조직+담임시간 xlsx+md | 정렬표 파일 |
| 6 | fidelity-guard | 정렬을 지키는 자 | 절대금액 금지·빼기 강제·목자 자원 검증 | 검증 리포트 |

## (c) 하위 산출물 (각 별도 섹션)
### 📊 자원 수요 vs 가용 갭 + 빼기 후보 (demand-estimator)
### 💰 예산 재배분 (비율·증감) (budget-allocator)
### 👥 조직 배치·리더 공백·양성 (org-mapper)
### ⏳ 담임 주간 시간 (기도·쉼 보호) (pastor-time-guard)
### 📋 예산·조직·시간 정렬표 (aligner-renderer — 목사 확정 후에만)
### 🛡️ 자원 정렬 검증 (fidelity-guard)

## (d) 마스터 통합 + 빼기·확정 초대 (별도 섹션)
### 📊 자원 갭 한눈 요약 (사람·돈·시간 어디가 모자란가)
### 💰 예산 재배분 제안 (비율·증감 — 절대 금액은 재정 담당과)
### ⏳ 담임 시간·소진 경고 (기도·쉼이 지켜지는가)
### ➖ 빼기 후보 (더하기 전 빼기)
### 🙏 "목표는 늘었습니다. 이를 위해 무엇을 멈춰 자원을 만드시겠습니까?"
   — [목사 검토·확정 HITL 대기. 빼기·예산 비율·배치 확정 전에는 최종 정렬표를 렌더하지 않는다.]
### (확정 완료 후) 📋 예산 배분안 + 조직 배치표 + 담임 시간 가이드 (xlsx + md)
### ➡️ 다음 단계: review-rhythm(#9)·plan-compiler(#10)로 전달
```

## 원칙
- **(d)에서 반드시 확정을 기다린다.** 빼기·예산 제시와 최종 정렬표 렌더 사이에 목사의 "무엇을 멈출까" 확정 HITL이 있다.
- 절대 금액을 지어내지 않는다 — 비율·증감만(전 섹션). 실제 금액은 재정 담당과.
- 빼기 없이 더하기만 하지 않는다(fidelity-guard 빼기 강제).
- 담임 기도·쉼을 자원으로 보호한다(목자가 소진되면 계획도 무너진다).
- 지표 점검은 #9, 행동 분해·담당은 #7. (#8은 자원 배분·갭 진단까지.)
- fidelity-guard 실패 시 (c)에 위반 노출, 해당 분석 재실행(임의 보정 금지).
```
