# 교회 건강 8영역 — 정의·채점 가이드

> health-map(건강의 정리자)이 사용. 8영역을 목사의 체감 1~5점으로 받되, 반드시 근거와 신뢰수준을 동반한다. 점수 단독 금지.

## 8영역 정의

| 영역 | 보는 것 | 회상 단서 질문 |
|---|---|---|
| **예배** | 주일·새벽·수요 예배의 살아있음, 회중 참여 | "예배 자리가 채워졌나요? 새벽이 살았나요?" |
| **말씀** | 설교·성경공부·개인 경건의 뿌리내림 | "성도들이 말씀에 굶주려 있나요, 식어 있나요?" |
| **교제** | 소그룹·구역·공동체의 따뜻함과 돌봄 | "서로 돌보나요, 모이기만 하나요?" |
| **전도** | 새 영혼 유입·전도 훈련·지역 접촉 | "올해 새 얼굴이 늘었나요?" |
| **양육** | 새신자→성장→리더의 제자훈련 흐름 | "정착한 사람이 자라고 있나요?" |
| **봉사** | 섬김·헌신·일꾼의 자발성 | "봉사자가 기쁘게 섬기나요, 지쳤나요?" |
| **선교** | 국내외 선교·후원·파송·지역 섬김 | "교회 밖을 향한 손길이 있나요?" |
| **재정** | 헌금 추이·청지기 의식·재정 건강 | "재정이 사역을 떠받치나요, 조이나요?" |

## 채점 척도 (1~5)
- **5** 매우 건강 — 자생적으로 살아 움직임
- **4** 건강 — 안정적, 작은 보강 필요
- **3** 보통 — 유지되나 정체, 돌봄 필요
- **2** 약함 — 눈에 띄는 누수·피로
- **1** 위태 — 시급한 개입 필요

## 채점 원칙
1. **근거 필수**: "전도 2점" → "왜요?" → "전도 행사가 무산됐어요" (basis 기록)
2. **추이 동반**: 재작년 대비 ↑↓→ + 그 근거
3. **신뢰수준**: 근거 분명 상 / 인상뿐 하
4. **앞선 회상 연결**: calendar·people·scale·heart에서 나온 단서를 영역에 이어 채점을 돕는다(백지 채점 금지)

## 교단 조정
시작 컨텍스트에 따라 영역의 무게가 다르다. 순복음은 기도/성령을 예배·말씀에 녹이고, 성례 중심 교단은 예배에 성례전 참여를 포함한다. 영역 자체는 8개로 유지하되 *설명과 예시*를 컨텍스트에 맞춘다(`denomination-context.md`).

## 가드레일
낮은 점수를 정죄로 쓰지 않는다. "약함을 아는 것이 돌봄의 시작." 모든 영역 5점을 강요하지 않는다 — 정직한 3점이 부풀린 5점보다 계획에 유익하다.
