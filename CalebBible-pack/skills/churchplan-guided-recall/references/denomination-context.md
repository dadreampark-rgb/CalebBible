# 교회 컨텍스트 1회 질문 (hardcoding 금지)

> 회상 시작 전 단 한 번 묻는다. 특정 교회를 가정하지 않는다 — 누구든 이 스킬을 쓸 수 있어야 한다. 답은 `meta.church_context`에 기록하고 이후 모든 질문 톤을 여기에 맞춘다.

## 질문 4개

### 1. 교단/전통
- 장로교 — 합동 / 통합 / 고신 / 합신 / 기타
- 감리교 (기감/기타)
- 성결교 (기성/예성)
- 침례교
- 순복음/오순절
- 성공회
- 정교회
- 루터교
- 독립/초교파/개혁
- 기타 (직접 입력)

### 2. 교회 규모대
- 개척 (~30명)
- 소형 (30~80명)
- 중소형 (80~150명)
- 중형 (150~300명)
- 기타 (직접 입력)

### 3. 지역 유형
- 대도시 / 중소도시 / 신도시 / 농어촌 / 해외 한인 / 기타

### 4. 목회 형태
- 담임 단독 / 부교역자 동역 / 다음세대 비중 높음 / 기타

## 컨텍스트별 톤 조정 가이드

| 컨텍스트 | 회상 질문 조정 |
|---|---|
| **순복음/오순절** | 8영역에서 기도·성령 체험·치유 사역의 결을 더 묻는다 |
| **성공회·정교회·루터교** | 성례전·전례력(교회력) 중심으로 절기 단서를 던진다 |
| **침례교·독립교회** | 회중 의사결정·자치 구조를 사람 회상에 반영 |
| **개척/소형** | 대형 전도축제·다부서 전제를 깔지 않는다. 한 사람 한 사람이 곧 통계 |
| **농어촌** | 고령화·계절(농번기)·이농을 사람·규모 회상에 반영 |
| **해외 한인** | 이민자 유입·귀국 이동·2세 언어를 깔때기에 반영 |
| **다음세대 비중 높음** | 교회학교·청년부를 출석·건강 영역에서 따로 분리 |

## 기본값
목사가 "그냥 일반적으로"라고 하면 중립 기본값(`denomination: "초교파/중립"`, 규모는 회상 중 추정)으로 진행하되 `church_context`를 비워 두지 않는다. fidelity-guard가 빈 컨텍스트를 위반으로 잡는다.
