# 시즌제 정렬 + 부하 점수 카탈로그 (단일 진실)

> season-aligner가 시즌 정렬 점검에, overload-marker가 부하 점수 산정에 쓴다. 박사님 프레임워크(01 라인 265 = 02 4C 컨설팅 포인트)의 시즌제 모델을 결정론적으로 적용한다.

## 1. 시즌제 모델 (01 라인 265 — "힘이 모인다")

> *"'시즌제'로 묶으면 회중의 집중도가 올라갑니다. 1분기=기초/영성, 2분기=전도/성장, 3분기=양육/리더, 4분기=공동체/감사 식으로 강조 시즌을 두면, 설교·행사·사역이 같은 메시지를 동시에 전하게 되어 힘이 모입니다."*

| 분기 | 기본 강조 시즌 | 절기 정렬 단서 | 한 방향(3중 정합)의 의미 |
|---|---|---|---|
| 1Q (1~13주) | **영성·기초** | 신년·사순 진입 | 설교=말씀 뿌리내림 / 행사=기도·헌신 / 사역=영성 캠페인(통독·새벽기도) |
| 2Q (14~26주) | **전도·성장** | 부활·맥추·성령강림 | 설교=복음·증인 / 행사=전도 축제·새가족 / 사역=정착 목표 점검 |
| 3Q (27~39주) | **양육·리더** | 여름·맥추감사 | 설교=제자도 / 행사=수련회·리더 세움 / 사역=소그룹·양육 목표 |
| 4Q (40~52주) | **공동체·감사** | 추수감사·대림·성탄 | 설교=감사·공동체 / 행사=감사절·성탄 / 사역=공동체 목표 마무리 |

- **시즌은 처방이 아니라 정렬 기준이다.** 교회 형편상 시즌 순서가 다르면(예: 2Q 양육) `meta.season_frame`이 진실이고, 이 표는 *기본값*이다. season-aligner는 `season_frame`에 맞춰 점검한다.
- **정렬 점검**: 각 분기의 실제 설교 강조(series.purpose)·행사(serves_axes)가 `season_frame[Q]`와 한 방향인가? 어긋나면 `aligned:false`+`note`로 *경고*(차단 아님 — 목사가 의도한 어긋남일 수 있다).

## 2. 부하 점수(load.score) 산정 rubric

한 주(week)의 부하를 결정론적으로 가산한다. **LLM이 점수를 임의로 부풀리지 않는다 — 아래 규칙으로만 더한다.**

| 요소 | 조건 | 가산 |
|---|---|---|
| 절기 고강도 | observance ∈ {종려주일, 부활주일, 성탄절, 추수감사주일, 맥추감사, 성령강림주일, 송구영신} | +2 |
| 절기 일반 | 그 외 observance 존재(특별주일·창립 등) | +1 |
| 핵심 행사 | events[]에 type="핵심" 1개당 | +2 |
| 정기 행사 | events[]에 type="정기" 1개당 | +1 |
| 캠페인 진행 | campaigns[] 1개당(통독·기도시즌 등 진행 주) | +1 |
| 연속 강해 | sermon이 직전 주와 같은 series_id로 4주째 이상 연속 | +1 |
| 마일스톤 점검 | milestones[]에 항목 존재(분기 점검 주) | +1 |

**level 매핑**: `score ≤ 1` → `낮음` · `2 ≤ score ≤ 3` → `보통` · `score ≥ 4` → `높음`.

- `factors`에는 가산에 기여한 요소를 사람이 읽을 라벨로 적는다(예: ["부활주일","핵심 행사 1"]).
- **연속 고강도**: `높음`(score≥4)이 2주 이상 연속되거나, 절기 고강도가 인접 주에 몰리면 overload-marker가 `density_warnings`(type="연속고강도", level="고")로 자동 표시한다(가드레일 ④).

## 3. 안식 보호 단서 (sabbath-protector)

- `inputs_echo.pastor_rest_input`의 주간은 무조건 `rest_plan`에 `type="담임휴가"`, `status="보호"`로 올린다(목사가 미리 비운 주간 사수).
- 고강도(level="높음") 구간 **직후** 주는 `type="안식제안"`, `status="권장"`으로 회복 주간을 제안한다.
- #4 `load_warnings` 중 `type="안식제안"`은 `rest_plan`으로 승계한다.
- **여백도 계획이다**: 비어 있는(부하 낮음) 주를 "채워야 할 빈칸"으로 보지 않는다. 쉼은 계획의 실패가 아니라 지속가능성의 설계다.
