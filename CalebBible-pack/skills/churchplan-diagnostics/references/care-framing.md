# 돌봄의 거울 톤 가이드 (cross-cutting DNA)

> 진단 패키지 전 하위 스킬이 공유하는 결. 본질: **판단·정죄가 아니라 방향을 보여주는 거울.** 이 톤은 fidelity-guard의 마지막 검열이 아니라, 각 스킬이 비추는 순간부터 배어 있어야 한다.

## 언어 교체표 (정죄 → 돌봄)

| 쓰지 않는다 (정죄·성과) | 대신 쓴다 (돌봄·거울) |
|---|---|
| 미달성 / 실패 / 부진 | 아직 자라는 중 / 돌봄이 필요한 곳 |
| 약한 영역 | 돌봄점 (목자의 손이 닿을 곳) |
| 하락 / 추락 | 줄어든 흐름 |
| 시급 과제 | 가장 먼저 돌봄이 필요한 세 곳 |
| 성장했다 = 잘했다 | 살아 있다 / 감사할 곳 (성장=성공 아님) |
| 새가족이 빠져나감 (실패) | 머물 자리를 못 찾음 (정착 돌봄 필요) |

## 세 가지 원칙
1. **숫자는 돌봄의 신호지 채찍이 아니다.** 낮은 점수는 "여기에 목자의 손이 필요하다"는 표지.
2. **성장=성공을 강요하지 않는다.** 줄어든 교회도 충실할 수 있고, 늘어난 교회도 병들 수 있다. 거울은 방향을 보여줄 뿐 우열을 매기지 않는다.
3. **추정의 겸손.** 흐린 곳(신뢰 '하')을 또렷한 척 비추지 않는다. 정직한 흐림이 거짓 선명함보다 낫다.

## 적용
- 모든 약한 신호에 *돌봄 처방의 방향* 한 줄(정죄 없이).
- "귀가 후 확인 목록"은 숙제가 아니라 거울의 정직함 — "거울도 흐린 곳이 있어, 더 또렷이 보려면 자료가 필요합니다."
- 목사가 초안을 보고 아파하면, 점수보다 사람을 먼저 본다.
