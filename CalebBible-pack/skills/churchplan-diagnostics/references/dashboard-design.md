# 진단 대시보드 렌더링 사양 (dashboard-builder)

> `scripts/build_dashboard.py`가 따르는 디자인 규약. 본질: 한 장 거울 — 한눈에·정직하게·따뜻하게. 추정이 사실로 둔갑하지 않게.

## 추정 충실도 규칙 (최우선)
- **모든 수치에 신뢰 배지**: 상(●●●)·중(●●○)·하(●○○) 또는 색 점. 배지 없는 수치 렌더 금지.
- **범위는 오차 띠로**: `range:[120,140]` → 막대가 아니라 *띠(band)* 로. 점값(131) 막대 금지.
- **신뢰 '하'는 흐리게**: 저채도/점선/"추정" 워터마크. 또렷한 확정처럼 그리지 않는다.
- **미회상은 "—"**: 0이나 빈 막대가 아니라 "— (워크샵 후 확인)".

## 따뜻한 팔레트 (정죄 아닌 돌봄)
- 배경: 미색/크림(#FBF8F3). 본문: 진회색(#3A3632).
- 강점·살아있음: 차분한 초록(#6B8E6F) — 쨍하지 않게.
- 돌봄점·낮음: **경보 빨강 금지.** 따뜻한 흙빛/주황(#C08552) 저채도.
- 추이: ↑ 초록 / → 회색 / ↓ 흙빛(빨강 아님).
- 강조선·헤드라인: 세피아(#594B3B).

## 레이아웃 (한 장, A4 인쇄 가정)
1. **헤더**: 교회명 · 회상연도 · 고지문 "추정 기반 진단 — 신뢰수준 표기, 워크샵 후 보강 권장"
2. **병목 헤드라인**: `findings.bottleneck_headline` 큰 세피아 글씨 (진단의 첫 문장)
3. **2단**: 좌) 8영역 inline SVG 레이더(8축, 신뢰 '하' 축 점선) / 우) 흐름 카드(오차 띠+배지)
4. **깔때기**: 유입→정착→양육→리더 4단계, 각 sense + 병목 단계 강조(흙빛)
5. **2단**: 좌) Top3 강점(초록) / 우) Top3 돌봄점(흙빛)
6. **귀가 후 확인 목록**: 신뢰 '하' 모음, 체크박스
7. **footer**: 범례(확정/추정/미회상 시각 구분) · "숫자는 돌봄의 신호입니다"

## SVG 레이더 사양
- 외부 JS/CDN 의존 없음(인쇄·오프라인 안정). 순수 inline `<svg>`.
- 8축 정팔각형, 1~5 눈금. 점수 다각형 채움은 반투명 세피아.
- 신뢰 '하' 영역 축은 점선 + 라벨에 "추정".
- 미회상 영역은 축만 그리고 점 생략.

## xlsx 정리표
- 시트1 "진단요약": 영역·수치·신뢰·추이·근거 컬럼.
- 시트2 "확인목록": 귀가 후 확인 항목.
- 신뢰 '하' 행은 옅은 배경 + "추정" 표기. 점값 단정 셀 금지(범위 텍스트).
