# 점검 리듬 카탈로그 — 신호등·월간 항목·빨강 템플릿·어젠다·일정 모델

> #9 하위 스킬이 공유하는 점검 구조 패턴. 콘텐츠를 *지어내는* 카탈로그가 아니라, 상속받은 지표·경고를 *어떤 틀로* 점검 구조에 앉힐지의 모델이다. 새 지표·수치를 만들지 않는다.

## 1. 신호등 정의 (돌봄 신호 — 성과 등급 아님)
지표의 색은 *우열 등급*이 아니라 *목자의 손이 어디로 가야 하는지*를 가리킨다.

| 색 | 뜻(돌봄 언어) | 쓰지 않는 말 |
|---|---|---|
| 🟢 | 잘 자라는 중 / 감사할 곳 | "달성·성공·우수" (성장=성공 강요 금지) |
| 🟡 | 살펴볼 곳 / 손이 닿아야 할 곳 | "주의·경고·부진" |
| 🔴 | 목자의 손이 가장 필요한 곳 | "실패·미달·낙제·문책" |

- 색은 **점검 시점에 목사가** 채운다. AI는 색을 미리 칠하지 않는다(미래값 둔갑 금지 — `status:null`).
- 색의 기준(예: target의 몇 % 이상 🟢)은 *제안*하되 확정은 목사 HITL. 추정 신뢰 '하' 지표는 색 대신 "실측 먼저"(verify_at_review)로 둔다.

## 2. 월간 1p 점검 항목 패턴 (5분 — 절제)
"매월 5분에 돌봄이 닿지 않은 양을 찾는다." 핵심 지표만. 모든 지표를 늘어놓지 않는다(KPI 대시보드 금지).

| 항목 유형 | 출처 | 한눈 질문(glance) 예 |
|---|---|---|
| 정착/돌봄 신호 | goals.양육·전도 | "이번 달 새로 온 분이 자리를 찾았는가?" |
| 영성 신호 | goals.영성 | "기도·말씀의 흐름이 살아 있는가?" |
| **목자 소진 체크(필수)** | resource.pastor_time(protected) | "이번 달 나의 기도·안식은 지켜졌는가?" |
| (선택) 주간 한 줄 | 강단·심방 | "이번 주 강단/심방에서 떠오른 한 사람?" |

- `pastor_sustainability_row`는 **반드시 포함**(목자가 소진되면 계획도 무너진다 — 가드레일 ④).
- 주간 옵션은 *원하는 목사만*. 01의 "매월/매주"를 흡수하되 확대하지 않는다.

## 3. 빨강(🔴) 대응 시나리오 템플릿 (정죄 아닌 돌봄)
빨강은 *실패 신고*가 아니라 *돌봄 호출*이다. 각 시나리오는 세 부분:

```
if_red:  "이 지표가 🔴이면 — [정죄가 아니라 어떤 돌봄의 표지인가]"
response: ["[함께 볼 지점]", "[떠올릴 한 사람]", "[반기 수정일에 다시 볼 것: 무리한 목표치였나]"]
not:     "성과 추궁·담당자 문책 금지(돌봄 점검이지 인사 평가 아님)"
```
- response의 마지막 줄은 늘 **반기 수정일로 연결**(목표치 자체가 무리였는지 점검 — 계획은 갱신으로 산다).
- 정죄 어휘 금지(금칙어 단일 진실원 — 8개): 실패·미달·부진·문책·추궁·징계·낙제·질책. ('책임 추궁'은 '추궁'에 포함)

## 4. 분기 점검 회의 어젠다 템플릿 (01 라인 300 — 스코어카드와 한 쌍)
분기 리뷰는 숫자만 보는 자리가 아니라 *함께 돌보는 회의*다.

```
① 신호등 함께 보기 (돌봄 신호로 — 등급 매기지 않기)
② 🔴 지표 돌봄 점검 (대응 시나리오대로)
③ 목자·일꾼 소진 점검 (#8 지속가능성 — 지친 손은 없는가)
④ 다음 분기 조정 (무리한 목표치 손보기 — 반기엔 공식 수정)
```

## 5. 연간 점검 일정 모델 (분기 4회 + 반기 1회)
| 시점 | 무엇 | 성격 |
|---|---|---|
| 1Q 말(≈3월) | 분기 리뷰 ① | 신호등·돌봄 점검 |
| **반기(6~7월)** | **공식 계획 수정일** | **못박기(필수)** — 현실과 동떨어진 계획을 손본다 |
| 2Q 말(≈6월) | 분기 리뷰 ② | (반기 수정과 묶을 수 있음) |
| 3Q 말(≈9월) | 분기 리뷰 ③ | 신호등·돌봄 점검 |
| 4Q 말(≈12월) | 분기 리뷰 ④ + 연말 회고 | 내년 계획의 씨앗 |

- 반기 수정일은 *공식*(official:true)으로 못박는다. "계획의 가치는 수립이 아니라 갱신"(01 라인 310).
- (선택) 자동 리마인드/리포트는 **구조 제안만**(`auto_reminder.proposed`). 실제 발송 자동화는 교회 환경에서 설정 — 여기서 cron을 켜지 않는다(자료 없이 작동·월권 방지).
